# Dépôt de démonstration Endless Sea

Ce dossier constitue un **référentiel d'extensions autonome** (docs/en/04 §4) servi
via l'URL brute GitHub :

```
https://raw.githubusercontent.com/j97970293-lang/endlesssea/main/demo-repo/index.json
```

Copiez cette URL dans **Extensions → Ajouter un dépôt** pour l'essayer sur l'app.

L'index liste uniquement des extensions fondées sur des **sources légales et
libres d'utilisation** (ici : les œuvres du domaine public de
l'Internet Archive via `archive.org`).
